# Yujin Kim's Personal Website

Source for [YJK-forDev.github.io](https://YJK-forDev.github.io), built with [Astro](https://astro.build/).

Modified from the [Space Ahead](https://github.com/djsiddz/space-ahead) template by Siddhesh Thadeshwar, licensed under the [GNU GPL v3](./LICENSE).

## Run locally

```sh
npx pnpm@11.1.3 install
npx pnpm@11.1.3 dev
```

## Where to edit

- Site info and links: `src/site.config.ts`
- About text: `src/pages/index.astro`
- News: `src/data/news.ts`
- Publications: `src/data/publications.ts`
- Colors and global styles: `src/styles/global.css`
